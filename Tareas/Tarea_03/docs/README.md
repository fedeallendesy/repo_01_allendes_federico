**Estudiante:** Federico Allendes  
**Proyecto:** Santiago a Destiempo  

## Proceso de Trabajo
Para la construcción de esta página web, comencé diagramando la estructura de la pieza narrativa enfocada en mi investigación sobre el "madrugón" y la brecha de conectividad de los buses Red en la periferia de Santiago. 

Siguiendo la pauta, utilicé únicamente HTML semántico para estructurar el contenido. Implementé etiquetas `<header>` y `<footer>` para el esqueleto de la página, agrupé el contenido principal de la crónica dentro de un `<div>`, y jerarquicé la información utilizando `<h1>`, `<h2>` y `<h3>`. 

La narrativa incluye párrafos descriptivos (`<p>`), listas ordenadas y no ordenadas (`<ul>`, `<ol>`) para resumir los hallazgos e hipótesis, enlaces externos (`<a>`) al DTPM, y la inserción de una imagen (`<img>`) que muestra la visualización de datos procesada en etapas anteriores del proyecto. Se agregaron atributos `id` y `class` para identificar las diferentes secciones.
